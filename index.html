Cloud sync (optional)

This dashboard has no server of its own, so by default your data only lives in this browser tab — use Export/Import to carry it around. If you want it to persist automatically across devices, connect a free Supabase project:
  1. Create a free project at supabase.com.
  2. In the SQL editor, run:
    create table dashboard_data (id text primary key, payload jsonb, updated_at timestamptz default now());
  3. Copy your Project URL and anon public key from Settings → API, paste them below.
Nothing is sent anywhere until you fill this in and click Save — it's entirely optional.
